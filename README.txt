مكتبة فيزياء المرحلة الرابعة - النسخة الاحترافية
=================================================
تشغيل:
1) افتح CMD داخل هذا المجلد.
2) python -m pip install -r requirements.txt
3) python app.py
4) افتح: http://127.0.0.1:5000

دخول الإدارة الافتراضي:
اسم المستخدم: admin
كلمة المرور: physics2026

مهم: قبل نشر الموقع على الإنترنت غيّر ADMIN_PASSWORD وSECRET_KEY إلى قيم قوية.
يمكن تغييرهما من متغيرات البيئة أو تعديل الكود.

المميزات:
- 9 مواد
- رفع ملف واحد أو عدة ملفات PDF
- تصنيفات: ملازم، محاضرات، ملخصات، أسئلة وامتحانات، مصادر، أخرى
- عرض PDF داخل المتصفح
- تحميل PDF
- حذف
- بحث
- إعلانات
- جدول دراسي
- إحصائيات التحميل
- ثيم داكن/فاتح
- تصميم متجاوب للموبايل
- SQLite
- جاهز للتهيئة للنشر على الإنترنت
